# Nivethitha Ramesh — Portfolio

Personal developer portfolio showcasing AI & Data Science projects, technical skills, and experience. Built with a modern editorial aesthetic, fluid animations, and a responsive design.

---

## ⚡ Tech Stack

- **Core:** React 18, Vite
- **Styling:** Tailwind CSS, Custom Design System
- **Animation:** Framer Motion
- **Icons:** Lucide Icons

---

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/Nivethitha-1131/Portfolio_.git

# Navigate to frontend and install dependencies
cd Portfolio_/frontend
npm install

# Start dev server
npm run dev
```

---

## 📁 Project Structure

```text
frontend/
├── src/
│   ├── components/    # Reusable UI & section components
│   ├── context/       # Theme context (Dark / Light)
│   ├── pages/         # Home, Journey, Innovation, Skills
│   ├── data/          # Projects, timeline, and skills data
│   └── styles/        # Global styling and Tailwind CSS
└── package.json
```
